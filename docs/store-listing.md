# Chrome Web Store 掲載内容（草案 v1.0.0）

申請フォームに貼り付ける文面のまとめ。

## 基本情報

- **名前**: SNSQuizLocker
- **概要（132字以内・manifest の description がそのまま使われる）**:
  > SNSを開くとクイズ（古典文学の書き取り・百人一首・聴音・詰将棋）を出題し、全問正解するまでブロックする見すぎ防止ツール。YouTube・X・Facebook・Instagram・TikTok・Reddit対応。
- **カテゴリ**: 仕事効率化（Productivity）
- **言語**: 日本語

## 詳細説明

```
SNSを見すぎてしまうあなたへ。SNSQuizLocker は、SNS を開くたびに「関所」としてクイズを出題し、全問正解するまでページをロックする自制ツールです。ただ時間を制限するのではなく、つい開いてしまった時間を暗記と教養の練習に変えます。

■ 出題される修行
・古典文学の書き取り — 徒然草・方丈記・こころ・人間失格など20作品。文章を覚えて書き取る。総ルビ付き、漢字でもかなでも解答可
・百人一首 — 上の句から下の句を答える
・重音聴音 — 同時に鳴る2音を聴き取る
・旋律聴音 — 4小節のメロディを聴いて五線譜に書き取る
・詰将棋 — 3手・5手・7手詰（やねうら王教材データより）

■ 対象サイト
YouTube（動画ごとにロック・ロック中は強制一時停止）、X(Twitter)・Facebook・Instagram・TikTok・Reddit（サイト単位でロック）。

■ 自分に合わせて選べる
ツールバーのアイコンから、出題するクイズとロックするSNSを自由に選択（初期設定は YouTube のみ）。ロック解除はタブを閉じるまで有効。翌日もまた修行から始まります。

■ 設計方針
・スヌーズや「あと5分」はありません。解きたくなければ閉じるだけです
・褒めたり煽ったりしません。正解したら淡々と次へ
・クリア後に「続けて修行」を選べば、SNSを見ずに練習だけ続けることもできます

■ プライバシー
データ収集・外部送信は一切ありません。設定はブラウザの同期領域にのみ保存されます。

オープンソース（MIT License）: https://github.com/Luis8492/SNSBlocker
```

## プライバシー関連（申請フォームの「プライバシー」タブ）

- **単一用途の説明**:
  > 利用者が選択したSNSサイトの閲覧前にクイズを出題し、正解するまでページをオーバーレイでロックする「見すぎ防止」ツールです。
- **権限の正当化**:
  - `storage` — 出題クイズと対象サイトの選択設定を保存するため（chrome.storage.sync）。
  - ホスト権限（youtube.com / x.com / twitter.com / facebook.com / instagram.com /
    tiktok.com / reddit.com）— 対象ページにクイズのオーバーレイを表示し、
    ロック中に動画を一時停止するため。ページ内容の読み取り・送信は行わない。
- **リモートコード**: 使用していない（全コード同梱、外部通信なし）。
- **データ使用**: 「ユーザーデータを収集しない」を選択。
- **プライバシーポリシーURL**（リポジトリ公開後に有効）:
  `https://github.com/Luis8492/SNSBlocker/blob/master/docs/privacy-policy.md`
