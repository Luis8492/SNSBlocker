# 重音(2音)（juon）

同時に鳴る2つの音を聴き取り、ピアノ鍵盤で答えるソルフェージュの聴音課題。

## 仕様

- **出題**: 下の音（C4〜C5）と度数（短2度〜完全8度の12種）をランダムに決めて2音を重ねる。
- **音源**: 音声ファイル不要。Web Audio API で基音＋倍音を合成して鳴らす
  （`juon.js` の `playNote`。減衰エンベロープ付きの簡易ピアノ風）。
- **入力**: ピアノの模式図（C4〜C6・CSS描画）。**鍵盤クリック＝試し弾き**（音が鳴るだけ）、
  **鍵盤下の○＝解答の選択**（2音まで）。音を確かめながら選べる。
- 「ヒント: 下の音だけ聴く」で下の音を単独再生できる。
- **正解判定は2音とも音名まで完全一致**（度数だけ合っていても位置が違えば不正解）。
- 不正解時は**自分の選んだ2音の正誤だけ**を色で示す（正しい音は明かさない）。
  何度でも聴き直してやり直す。
- 正解時は次の出題画面の冒頭に「正解」と表示し、フェードアウトする
  （鍵盤だけの画面は問題が変わっても見た目が同じで、進んだことに気づきにくいため）。
- 1ラウンドは3問（`juon.js` の `QUESTIONS_PER_ROUND`）。

## 将来
