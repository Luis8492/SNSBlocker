# 百人一首（hyakunin）

百人一首の書き取りクイズ。**上の句は常に表示**され、覚えて入力するのは**下の句のみ**。

## 古典文学（koten）との違い

- 上の句（5-7-5）は覚える画面・入力画面・diff 画面のすべてで表示される。
- 「覚えた」ボタンに**5秒の待機ゲージが無い**（すぐ押せる）。
- 1ラウンドは全100首から**重複なしランダムに3首**（`hyakunin.js` の `POEMS_PER_ROUND`）。

採点（表記ゆれの正規化・LCS diff）は koten と同仕様。ただしプラグインの自己完結を
保つため、ロジックは koten に依存せず**このフォルダ内に重複して持つ**
（フォーク運用でどちらかを消しても壊れないように）。

## データ

`poems.js`（`Kansho.data.hyakuninPoems`）に全100首。各首は
`{ no, kami（上の句）, shimo（下の句）, author }`。

- 出典: 近江神宮「小倉百人一首一覧」の表記（歴史的仮名遣い）に基づく。
- 生成時に「上の句＋下の句の連結が原文と一致する」ことを全首検証済み。
