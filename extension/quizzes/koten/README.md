# 古典文学（koten）

古典文学の書き取りクイズ。一続きの文章を複数の segment に分けて出題し、
覚えて入力する。1ラウンド＝1作品の全 segment。

## 動作の流れ

1. 文章と「**覚えた**」ボタンが表示される（文章は**コピー不可**）。
   「覚えた」は表示から**5秒の待機ゲージ**が満ちるまで押せない。
2. 「覚えた」を押すと入力画面へ。文章は隠れる（入力欄は**貼り付け不可**）。
   「ヒント」でぼかした原文を表示、「もう一度見る」で表示画面に戻れる。
   ヒントボタンは**押すたびにぼかしが1px弱まり**（6px→最低3px）、
   押した後は**5秒のクールダウン**を経て再び押せる。
3. 入力して「**Submit**」（Ctrl+Enter でも送信）：
   - 正解 → 淡々と次の文章へ（褒めたり「正解！」と出したりはしない）。
   - 不正解 → **diff 表示**（誤り＝赤の取り消し線、抜け＝緑）＋「**やり直す**」。

## データ

`passages.js`（`Kansho.data.kotenPassages`）に収録。作品はランダムに1つ選ばれ、
その全 segment が出題される。編集すれば作品や分割を自由に追加・変更できる。

- 古典・海外: 徒然草・方丈記・枕草子・源氏物語・平家物語・坊っちゃん・論語・Hamlet・The Prince
- 近代文学（青空文庫より）: こころ・人間失格・吾輩は猫である・羅生門・銀河鉄道の夜・
  走れメロス・蜘蛛の糸・斜陽・蟹工船・檸檬・人間椅子

### ルビ（ふりがな）

青空文庫風の「**漢字《かな》**」記法で書く。ルビは直前の漢字連続部分に振られる
（かな混じりに振る場合は「｜とじ籠《こも》る」のように `｜` で範囲を示す）。

- 表示画面・ヒントでは `<ruby>` タグのふりがなとして描画される。
- 採点ではルビ箇所を**本文（漢字）・よみ（かな）のどちらで書いても正解**
  （ふりがな自体を重ねて入力する必要はない）。

## 採点（表記ゆれの許容）

**句読点・記号・空白・全角/半角・英字の大文字小文字**の違いは正規化して無視する
（`koten.js` の `normalize`）。空白の揺れ（改行・連続スペース・前後の空白）も許容。

**漢字⇔かなの表記ゆれ**は、ルビが振られた箇所に限り許容する：各ルビ箇所は
本文（漢字）でもルビのよみ（かな）でも正解（`tokenizeRuby` / `matchesAny`）。
混在（一部だけかな書き）も可。逆に**原文がかなの箇所を漢字で書いた場合は不正解**
（よみの情報がないため判定できない）。よみ自体は 1 文字単位で厳密
（歴史的仮名遣いのゆれ等は吸収しない）。

diff は入力の表記（漢字/かな）に最も近い解釈の期待文字列を選んでから
（`chooseExpected`、同点なら漢字優先）、正規化空間で LCS アラインメントし、
元の文字で描画する。

## 難易度の調整

- 文章を長く／短くする → `passages.js` の各 `segments` を編集。
- 問題数を変える → `segments` の数を増減する（出題数＝`segments` の数）。
  長い範囲を課したい作品は 4 分割・5 分割…と増やせばよい。
