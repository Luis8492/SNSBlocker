# 旋律聴音（senritsu）

自動生成された4小節の両手の演奏を聴き取り、大譜表（ト音＋ヘ音）に書き取る
ソルフェージュの聴音課題。**左手も聴音対象**。

## 出題の生成

- **ハ長調・4分の4拍子・4小節**固定。データファイルは持たず毎回生成する。
- 小節ごとに **I / IV / V** からランダムに和音を選ぶ（進行・終止の制約なし。
  聴音の練習が目的であり、よい曲を作るのが目的ではない）。
- **左手** = その和音の分散和音（root-5th-3rd-5th を4分で刻む。C3まわりの低音域）。
- **右手（メロディ）** = 音階内（ダイアトニック）・音域 **C4〜C6**。
  2拍ごとに「2分×1」か「4分×2」をランダムに選び、音高は順次進行を基本に
  たまに跳躍するランダムウォーク。休符なし。**音価は2分と4分のみ**。
- 音源は Web Audio API で合成（音声ファイル不要）。テンポ ♩=84。

## 入力（大譜表への書き取り）

- 音価パレット（**2分音符 / 4分音符**）を選ぶと、譜面上のマウス位置に
  「置かれる予定の音符」が**縦位置スナップ済みのゴースト**として表示され、
  **クリックで確定**する（配置時に音は鳴らない）。
- **上段クリック=右手、下段クリック=左手**。横位置は自由（大まかでよい）。
  **好きな時間位置に順不同で置ける**ので「後ろの音だけ先に書く」「途中だけ直す」ができる。
- 譜面右上の「**整列**」ボタンで、各小節に属する音符が**小節内で左詰め・拍にスナップ**
  し直される。**送信時にも自動で整列**してから採点する。
- **右クリックで音符を削除**（最も近いもの）。「一つ戻す」（最後に置いた音符を消す）
  「最初から」も使える。
- **再生は無制限**。「出題を聴く」は**カウントイン4拍**（クリック音）の後に演奏が始まる。
  「入力を聴く」で自分の書き取りも再生できる（こちらはカウントインなし・即再生）。
  「停止」で再生を中断できる。
- 調号はハ長調のため描画なし（調を増やす場合は調号描画の追加が必要）。

## 採点

- 両手とも、発音タイミング・音高・音価が**すべて一致**で正解。
- 不正解時は**自分の音符の正誤だけ**を色で示す（緑=合致・赤=不一致。
  正解は明かさない）。入力は保持され、修正して再送信できる。
- 正解時は次の出題画面の冒頭に「正解」を表示してフェードアウト。
- 1ラウンドは3問（`senritsu.js` の `QUESTIONS_PER_ROUND`）。

## 調整どころ

- テンポ → `BEAT_SEC`／右手の音域 → `RH_MIN`/`RH_MAX`／跳躍の頻度 → `makeQuestion` 内の乱数重み。
- 調や拍子を増やす場合は `SCALE_SEMITONES`・`CHORDS`・譜面描画（調号）の拡張が必要。
